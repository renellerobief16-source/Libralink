System Capabilities

Engineered for Resource Sharing

Built specifically to eliminate catalog silos between member institutions and automate the borrowing lifecycle.

🔍 Centralized Inter-Campus OPAC
Unified search query engine aggregates titles, authors, and Dewey call numbers across GNC and Santa Rita College simultaneously.
⚡ Live Holding & Copy Verification
Instant inventory computation displays exactly how many physical copies are on shelf, on loan, or reserved in real-time.
🔄 Inter-Library Loan (ILL) Brokering
Students can request books housed at the partner campus; cross-school circulation queues alert counter staff for fulfillment.
🛡️ Multi-Tenant RBAC Security
Strict PostgreSQL Row-Level Security ensures GNC and SRC maintain private institutional autonomy while sharing catalog discovery.
Patron Experience

How It Works for Students

Four simple steps to borrow books anywhere within the consortium network using any smartphone or web browser:

1
Discover Across Campuses
Enter keywords or course subjects to locate print books available at GNC or SRC.
2
Submit Instant Borrow Request
One click dispatches request to the circulation queue for librarian approval.
3
Receive Encrypted QR Pass
Upon approval, a dynamic QR code token is generated on the student's mobile dashboard.
4
Counter Scan & Release
Librarian scans pass with barcode/camera scanner for paperless check-out release.
